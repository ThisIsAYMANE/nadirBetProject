BasketballApiDocumentation

1. Base Configuration
✅ Description

All endpoints:

Method: GET
Base URL:
https://v1.basketball.api-sports.io/
💻 cURL Example
curl --request GET \
  --url 'https://v1.basketball.api-sports.io/leagues' \
  --header 'x-apisports-key: YOUR_API_KEY'
💻 JavaScript Example
const response = await fetch('https://v1.basketball.api-sports.io/leagues', {
  method: 'GET',
  headers: {
    'x-apisports-key': 'YOUR_API_KEY'
  }
});
const data = await response.json();
