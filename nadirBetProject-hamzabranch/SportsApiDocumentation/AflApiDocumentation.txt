AflApiDocumentation

1. Base Configuration
✅ Description
REST API (GET only)
Authentication via header
Base URL:
https://v1.afl.api-sports.io/
💻 cURL Example
curl --request GET \
  --url 'https://v1.afl.api-sports.io/leagues' \
  --header 'x-apisports-key: YOUR_API_KEY'
💻 JavaScript Example
const response = await fetch('https://v1.afl.api-sports.io/leagues', {
  method: 'GET',
  headers: {
    'x-apisports-key': 'YOUR_API_KEY'
  }
});
const data = await response.json();
📌 Notes
Same architecture as other API-Sports APIs (football, basketball)
Provides AFL data: leagues, teams, games, stats

🏆 3. Leagues

curl -X GET "https://v1.afl.api-sports.io/leagues" \
  -H "x-apisports-key: YOUR_API_KEY"
[
