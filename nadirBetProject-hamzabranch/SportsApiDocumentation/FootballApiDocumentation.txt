1. Authentication & Base Request
✅ Description

All requests:

Use GET only
Require an API key in headers
Use base URL:
https://v3.football.api-sports.io/
💻 cURL Example
curl --request GET \
  --url 'https://v3.football.api-sports.io/countries' \
  --header 'x-apisports-key: YOUR_API_KEY'
💻 JavaScript (Fetch)
const response = await fetch('https://v3.football.api-sports.io/countries', {
  method: 'GET',
  headers: {
    'x-apisports-key': 'YOUR_API_KEY'
  }
});
const data = await response.json();
📌 Notes
No POST, PUT, DELETE → read-only API
JSON responses only
🌍 2. Countries Endpoint
✅ Description

Returns all countries with available football data.

💻 cURL
curl --request GET \
  --url 'https://v3.football.api-sports.io/countries' \
  --header 'x-apisports-key: YOUR_API_KEY'
📌 Notes
No parameters required
Used as entry point for leagues filtering
🏆 3. Leagues Endpoint
✅ Description

Retrieve leagues and seasons.

💻 cURL (All leagues)
curl -s "https://v3.football.api-sports.io/leagues" \
  -H "x-apisports-key: YOUR_API_KEY"
💻 cURL (Specific league seasons)
curl -s "https://v3.football.api-sports.io/leagues?league=39" \
  -H "x-apisports-key: YOUR_API_KEY"
💻 JS Example
fetch('https://api-football.com/v3/leagues', {
  method: 'GET',
  headers: {
    'X-RapidAPI-Key': 'your-api-key'
  }
})
.then(res => res.json())
.then(data => console.log(data));
📌 Notes
Supports filters: id, name, country, season
Example: league 39 = Premier League
