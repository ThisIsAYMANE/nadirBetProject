HockeyApiDocumentation

1. Base Configuration
✅ Description
REST API (GET only)
Authentication via API key header
Base URL:
https://v1.hockey.api-sports.io/
💻 cURL Example
curl --request GET \
  --url 'https://v1.hockey.api-sports.io/leagues' \
  --header 'x-apisports-key: YOUR_API_KEY'
💻 JavaScript Example
const response = await fetch('https://v1.hockey.api-sports.io/leagues', {
  method: 'GET',
  headers: {
    'x-apisports-key': 'YOUR_API_KEY'
  }
});
const data = await response.json();
📌 Notes
Same structure as all API-SPORTS APIs
Covers leagues, teams, players, games, standings, etc.

🏆 3. Leagues
💻 Example
curl -X GET "https://v1.hockey.api-sports.io/leagues" \
  -H "x-apisports-key: YOUR_API_KEY"
[
  {
    "endpoint": "/leagues",
    "description": "Get leagues and competitions",
    "params": ["id", "name", "country", "season", "type", "search"]
  },
  {
    "endpoint": "/leagues/seasons",
    "description": "Available seasons",
    "params": []
  }
]
