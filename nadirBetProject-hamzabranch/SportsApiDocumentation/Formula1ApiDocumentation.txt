Formula1ApiDocumentation

1. Base Configuration
✅ Description
REST API (GET only)
Authentication via header
Base URL:
https://v1.formula-1.api-sports.io/
💻 cURL Example
curl --request GET \
  --url 'https://v1.formula-1.api-sports.io/races' \
  --header 'x-apisports-key: YOUR_API_KEY'
💻 JavaScript Example
const response = await fetch('https://v1.formula-1.api-sports.io/races', {
  method: 'GET',
  headers: {
    'x-apisports-key': 'YOUR_API_KEY'
  }
});
const data = await response.json();
📌 Notes
Same architecture as other API-SPORTS APIs
Covers races, drivers, teams, standings, rankings

🏎️ 4. Competitions / Leagues (Championships)
💻 Example

  -H "x-apisports-key: YOUR_API_KEY"
